Tarea 3 · Módulo 3: Reconocimiento Pasivo y Activo Básico

Parte 1 – Reconocimiento Pasivo con Google Dorks

Cada alumno debe:

1. Crear 8 búsquedas diferentes usando:

   * `site:`
   * `filetype:`
   * `inurl:`
   * `intitle:`
   * `"frase exacta"`
   * `OR`
   * `-` (exclusión)

2. Documentar:

   * El dork usado
   * Qué encontró
   * Si representa un riesgo o no
   * Captura de pantalla

👉  Objetivo: Que entiendan cómo se expone información públicamente.


Parte 2 – Investigación en GHDB

Entrar a Exploit Database y:

1. Buscar 3 dorks
2. Explicar:

   * Qué buscan
   * Qué tipo de exposición detectan
   * En qué categoría están

👉 Objetivo: Que entiendan cómo se clasifican las exposiciones.


Parte 3 – Maltego (Mapa Visual)

En Maltego deben:

1. Crear un grafo nuevo

2. Agregar:

   * Un dominio autorizado o example.com

3. Ejecutar mínimo:

   * Domain → DNS
   * DNS → IP
   * IP → Location

4. Tomar captura del grafo final.

👉 Objetivo: Que visualicen cómo se conecta la infraestructura.


Parte 4 – Reflexión (1 hoja)

Responder:

* Diferencia entre reconocimiento pasivo y activo.
* ¿Por qué el reconocimiento sin autorización puede ser ilegal?
* ¿Qué aprendiste sobre la exposición de información?

Modulo-3-Reconocimiento

Con:
* PDF con evidencias
* Capturas
* Explicaciones
* README explicando lo que hicieron
